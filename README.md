# Python-Voice-Assistant-Hands-Free-App-Launcher
A voice-controlled assistant built in Python that listens to natural speech commands and instantly opens websites or system applications — no keyboard needed

<img width="1536" height="1024" alt="Assistant" src="https://github.com/user-attachments/assets/be533c4f-fcc8-4902-8aad-6ab1b6239e9c" />

Just say:

🗣️ “Open Google”
🗣️ “Open YouTube”
🗣️ “Open Calculator”

…and it responds out loud and executes the command 🎯

✨ Features

🎤 Speech Recognition (real-time voice commands)

🔊 Text-to-Speech responses (Jarvis talks back!)

🌐 Opens popular websites (Google, YouTube, GitHub, Facebook)

💻 Launches Windows apps (Calculator, Notepad, CMD)

🧠 Flexible command matching (no strict phrases)

🪶 Lightweight & beginner-friendly

❌ No wake word required — just speak naturally

🛠️ Tech Stack

Python 3.13

speech_recognition

sounddevice

pyttsx3 (offline text-to-speech)

webbrowser, os

▶️ How to Run
pip install SpeechRecognition sounddevice pyttsx3 numpy
python main.py


Make sure your microphone is enabled in Windows settings 🎤

🗣️ Example Commands

“Open Google”

“Open YouTube”

“Open GitHub”

“Open Calculator”

“Exit”
